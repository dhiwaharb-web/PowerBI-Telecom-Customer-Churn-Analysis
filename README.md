# Telecom Customer Churn Analysis

## Project Overview

This project analyzes customer churn patterns in a telecom company to identify the key factors influencing customer retention, churn, and revenue loss.

The project combines **Python, SQL, and Power BI** to perform data cleaning, exploratory analysis, business analysis, and interactive dashboard reporting.

---

## Project Objective

The main objectives of this project are:

- Analyze overall customer churn.
- Identify customer segments with high churn rates.
- Understand how contract type, tenure, internet service, payment method, and demographics affect churn.
- Identify major reasons why customers leave.
- Measure revenue generated by churned customers.
- Identify high-value customers at risk of churn.
- Present actionable insights through an interactive Power BI dashboard.

## Project Workflow

### 1. Data Loading

The telecom customer dataset was loaded into Python using Pandas.

### 2. Data Quality Analysis

The dataset was checked for:

- Missing values
- Duplicate records
- Invalid values
- Data types
- Business-logic-based missing values

Missing values were analyzed based on their business meaning rather than automatically removing them.

For example, missing internet-related fields can occur when a customer does not have internet service.

### 3. Data Cleaning

The following cleaning steps were performed:

- Verified data types.
- Checked duplicate records.
- Validated missing values using business logic.
- Filled missing values in the `Offer` column with `No Offer`.
- Identified invalid negative monthly charge values.
- Created a `Churn Flag` variable for analysis.
- Created customer segmentation fields such as `Tenure Group` and `Age Group`.

### 4. Exploratory Data Analysis

## Key Findings

- Customers with shorter tenure show significantly higher churn rates.
- Month-to-month customers have the highest churn rate compared with longer-term contracts.
- Customers using different internet types show noticeable differences in churn behavior.
- Churn is concentrated among specific customer segments and service categories.
- Competitor-related issues are a major contributor to customer churn.
- Churned customers account for a meaningful portion of total revenue.
- A smaller group of high-value customers contributes substantially to overall revenue.

---

## Business Insights

The analysis suggests that the company should focus on:

- Improving retention during the early customer lifecycle.
- Encouraging customers to move from month-to-month contracts to longer-term plans.
- Addressing competitor-related service and pricing concerns.
- Improving customer support and service experience.
- Monitoring high-value customers who show churn risk.
- Developing targeted retention offers for high-risk customer segments.
